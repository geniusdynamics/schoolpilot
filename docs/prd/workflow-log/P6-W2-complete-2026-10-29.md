## The dashboard error seen during the wave

The failing tab was `localhost:5241`, a Vite server rooted in the C01 worktree, not the main app.
Its dependency optimizer had a stale generation: the dashboard page served 200, but `recharts` (used
by every dashboard) returned **504 Outdated Optimize Dep**, so React's lazy import failed with
`Failed to fetch dynamically imported module`. A five-hour-old orphaned Playwright headless
Chromium, whose parent was gone, was pinning the machine at 100% CPU; the cold optimizer could not
finish. The orphan was stopped, the server restarted, and the main checkout on 5299 and 5241 were
rechecked with the dashboard module and `recharts` both 200. This was an environment/dev-server
fault, not app code or the production database. A production build does not use that path.
