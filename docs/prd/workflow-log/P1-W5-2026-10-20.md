**Integration fixes in this wave**

- `e36fbe3` — the five byte-identical module copies of the canonical repository provider collapsed into one shared module (`−500` lines).
- `3b8b773` — **a real browser bug found by running the app**: the canonical worker and the legacy layer both installed the default OPFS SAH pool, so the second could not create its access handles ("another open Access Handle or Writable stream associated with the same file") and every canonical page showed "the canonical data layer is unavailable". The canonical pool now has its own directory, and the provider logs the cause of an open failure (dev shows it too).
- `8013cc1` - Vite no longer watches `.claude/worktrees/**`; every agent write had been causing a reload or a cache-clearing full reload.
- `48b2c74` - **a second real browser bug**: the finance hubs rendered canonical content without mounting `CanonicalRepositoryProvider`, so a direct load or a reload of `/finance/invoicing`, `/finance/payments`, `/finance/fee-rules`, `/finance/fee-configuration` or `/finance/student-fee-history` failed with "useCanonicalRepository must be used within a CanonicalRepositoryProvider". The golden path had hidden it by reaching the hubs through an in-app route change from a page that had already mounted the provider. All five hubs now mount it, and GP-1 loads two of them directly so it cannot regress silently.

## Known gaps (stated, not hidden)

- **The canonical model does not cover** inventory stock, library loans, nutrition meals, payroll, the finance ledger, admission applications, student categories/dormitories or student clearance. Those pages keep the legacy layer with `GAP(P1-E0x)` markers naming the missing entity.
- **Pages still on the legacy layer, by name:** transport routes and student transport assignments; general receipts; supplier and customer invoices (and suppliers); the student promotion and clearance screens; the bulk pages (roll numbers, student update, stream creation, staff update); the seven report pages listed in the five-tree guard; and the GAP pages of inventory, library, nutrition, HR and the remaining finance ledger pages.
- **Student masterlist columns Category and Dormitory render empty** — a visible consequence of the missing student-category/dormitory entities.
- **`AppDataContext` CRUD writes remain, but not every member has a live consumer**: `recordStudentPayment`, the supplier-contract CRUD and the fee-template-item writers (reached only through `useFinanceData`) are called by no page and can be retired now. The rest still have consumers through the module augmentations and need those consumers moved first (E06's blocker, with the exact change listed).
- **Module mock fixtures remain** for the GAP pages that read the legacy collections, and `mockPathsRetired.test.ts` pins that debt. **`collections.ts` is not pinned by any test** — it is the live provider registry, not a fixture, and the debt it carries is the unmodelled collections themselves.
- **GP-6's full pipeline** (application → screening → interview → offer → acceptance) is not modelled; Q02's spec is scoped to the admit step.
- A transaction on the adapter is refused while another is open rather than queued, so two services writing concurrently fail instead of waiting. The repository now joins an ambient transaction, so a service called inside another's transaction shares it instead of failing.
