📝 Manual Testing Instructions

  1. Test Valid Login:
    • Go to Login Page
    • Try logging in with each demo credential above
    • Verify you are redirected to the dashboard
    • Check browser console for any errors
  2. Test Invalid Login:
    • Try logging in with wrong password (e.g., admin/wrongpass)
    • Try logging in with non-existent user (e.g., baduser/badpass)
    • Try logging in with empty fields
    • Verify error messages are shown
    • Check if errors are reported to Bugsink
  3. Test Error Tracking:
    • Go to Error Test Page
    • Click "Trigger Test Error" button
    • Verify error is sent to Bugsink dashboard
