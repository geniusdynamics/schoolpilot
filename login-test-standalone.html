📋 Test Instructions

How to Run Tests:

  1. Navigate to Login Page: Go to http://localhost:5173/#/login in another tab
  2. Open Developer Tools: Press F12 or right-click → Inspect
  3. Go to Console Tab: Click on the "Console" tab in developer tools
  4. Load Test Script: Click "Load Test Script" below to inject the test functions
  5. Run Tests: Type runAllTests() in the console and press Enter
  6. Monitor Results: Watch the console output and check this page for updates
Note: The tests will automatically fill login forms, submit them, and verify results. Each test includes error reporting to Bugsink for tracking purposes.
