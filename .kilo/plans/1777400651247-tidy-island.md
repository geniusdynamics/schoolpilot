# Plan: Align Hub-and-Spoke Implementation with Spec

## Current State Summary

The spec-specified hub-and-spoke model was implemented but with significant deviations: hubs were rolled out to all 11 modules before the Administration POC was validated, creating 31 hub pages total. Key anti-patterns exist: over-consolidated hubs (Accounting = 8 tabs, SchoolConfiguration = 7 tabs), missing `routes` arrays (HR), duplicate nav entries, and a broken FullWidth toggle.

---

## Issue 1: HR Module Missing `routes` Array (CRITICAL)

**Location:** `src/modules/hr/moduleDefinition.tsx`  
**Problem:** The module definition has no `routes` property. The DynamicRoutes component reads `metadata.routes` to register route entries. Without it, all HR pages return 404 at the route level.

**Fix:** Add `routes` array to HR moduleDefinition matching all navigable pages:
```typescript
routes: [
  { path: '/hr/dashboard', page: 'HRDashboardPage' },
  { path: '/hr/payroll', page: 'PayrollHubPage' },
  { path: '/hr/staff-bio-data', page: 'StaffBioDataPage' },
  { path: '/hr/payroll-item-types', page: 'PayrollItemTypesPage' },
  { path: '/hr/payroll-periods', page: 'PayrollPeriodsPage' },
  { path: '/hr/payslips', page: 'PayslipsPage' },
  { path: '/hr/staff-salary-settings', page: 'StaffSalarySettingsPage' },
]
```

## Issue 2: FullWidth Toggle Uses Raw DOM Instead of Context

**Location:** `src/components/TopOverflowMenu.tsx` (lines 105-113)  
**Problem:** The "Toggle Full Width" menu item calls `document.body.classList.toggle('full-width')` instead of `useFullWidth().toggleFullWidth()`. This bypasses `FullWidthContext`, so `isFullWidth` state never updates, and the sidebar never re-filters items.

**Fix:** Import `useFullWidth` from `@/contexts/FullWidthContext` and call `toggleFullWidth` from the context. Additionally add `isFullWidth` to `UIStateStore` (or similar store that `LayoutNew` reads) so the layout can apply CSS changes.

```typescript
import { useFullWidth } from '@/contexts/FullWidthContext';
// Inside component:
const { toggleFullWidth, isFullWidth } = useFullWidth();
// Replace the action:
action: () => {
  toggleFullWidth();
  setIsOpen(false);
}
```

**Location:** `src/modules/administration/moduleDefinition.tsx` (lines 61 and 72)  
**Problem:** `studentHealth` is registered twice — once as active standalone (line 61) and once as deprecated with redirect (line 72). Same path, same page, contradictory modes. The active entry should be removed since the deprecated one handles it via redirect.

**Fix:** Remove line 61 (the active standalone entry). Keep line 72 (deprecated with `redirectTo: '/administration/students?tab=health'`). The `StudentsListPage` doesn't have a `health` tab — keep the redirect but remove the standalone entry so it redirects properly.

Also verify the route is registered in the `routes` array. Add if missing:
```
{ path: '/administration/student-health', page: 'StudentHealthRecordsPage' }
```

## Issue 4: SchoolConfigurationPage Exceeds Tab Budget (Anti-Pattern)

**Location:** `src/modules/administration/pages/SchoolConfigurationPage.tsx`  
**Problem:** 7 tabs (departments, designations, classes, clubs, dormitories, categories, partners). Spec defines 6. The `classes` tab causes the second row, making tab names wrap to 2 lines.

**Spec reference:** The spec defines SchoolConfigurationPage tabs as: departments, designations, dormitories, categories, clubs, partners (6 tabs). The `classes` tab was added but classes should redirect via `classes` → configuration instead.

**Fix:** Remove `classes` from SchoolConfigurationPage tabs. Replace with a standalone `ClassesPage` entry in the nav (visible in standard+fullwidth modes). Add corresponding route. The `classes` deprecated redirect in the nav should point to the standalone classes page instead of the hub.

New nav entries in admin moduleDefinition:
```
{ name: 'navigation:administration.classes', path: '/administration/classes', icon: UserGroupIcon, page: 'ClassesPage', showInModes: ['standard', 'fullwidth'] },
```

Update the deprecated redirect:
```
// Remove classes from SchoolConfigurationPage tabs
// Change redirect: '/administration/configuration?tab=classes' → just '/administration/classes' (standalone)
```
